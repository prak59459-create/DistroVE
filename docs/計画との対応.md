# 計画書との対応

計画書（Distro VE 計画書、2026-11-19）の項目（Q 番号）ごとに、実装した内容・状態・主なファイルをまとめます。
状態は ✅ 実装済み、🟡 一部（制約あり）、⏸ 未実装・利用者の判断待ち です。

## 第 2 章「先に決めたい点とリスク」の方針案

| 論点 | 採った方針 | 状態 |
| --- | --- | --- |
| 予算と公開 | 予算 0 円で作れる構成にした（外部の有料サービスなし、CI は公開リポジトリの無料枠）。App Store への提出は開発者アカウント加入後に Swift Playgrounds から行う | ⏸ 公開時期・年会費は利用者の判断 |
| GitHub 経由の更新 | App Store 版は通常の更新のみ。GitHub から受け取るのはテンプレート・LUT のデータだけ（`content/`、ハッシュ確認・次回起動で反映）。Swift Playgrounds 版のプログラムの差分更新は「アプリ内では不可」と判断（下の「試作で確かめたこと」） | ✅ データ更新 / 🟡 プログラムの更新は不可 |
| 動画処理の仕組み | AVFoundation と Core Image（Metal）だけで実装。FFmpeg は使わない | ✅ |
| 言語と作り方 | Swift + SwiftUI（タイムラインは UIKit）。Web 技術は使わない | ✅ |
| 読み込み形式 | MP4・MOV・HEVC・画像・音声に絞った。MKV・WebM・AVI は案内を出して断る | ✅ |
| プライバシー | 動画本体は端末外に出さない。サーバーを使うのは、端末内で文字起こしできない端末で利用者が許可したときの音声だけ | ✅ |
| 作る量 | 公開前に段階を分けて実装（下の「段階」） | ✅ 段階 1〜5 の機能を実装、段階 6 は実機確認が残る |

## 試作で確かめたこと（第 9 章の「最初にやること」2）

- **外部ライブラリ**: 使わずに全機能を作れた（AVFoundation・Core Image・Vision・Speech・Accelerate など Apple 標準のみ）。Swift Playgrounds では外部パッケージを URL で追加できるが、`Package.swift` はアプリの設定を変えると作り直されるため、手で足したものが消える恐れがある。外部ライブラリを使わない構成にした。
- **GPU 処理**: 合成・色・エフェクトは Core Image を Metal で動かしている。macOS の CI で書き出しテストが GPU で通ることを確認（`FrameRenderer.usesGPU`）。
- **GitHub からの差分更新（再起動で反映）**: データ（テンプレート・LUT）は実装済み。プログラムは、Swift Playgrounds が作ったアプリが自分のソースを書き換えて作り直す仕組みが無いため、アプリ内からは更新できない。新しい `DistroVE.swiftpm` を取り込み直す運用にする。
