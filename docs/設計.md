# 設計メモ

## 全体

```
UI（SwiftUI・UIKit）  ── 操作 ──▶  EditorController.apply(名前) { project を書き換える }
                                       │  変更前の Project を UndoHistory に積む（無制限・古い履歴はディスクへ）
                                       │  1.5 秒後に自動保存（ProjectStore、原子的な書き込み）
                                       ▼
                               TimingKey（時間の並びの要約）が変わった？
                         はい ─▶ CompositionBuilder で合成を作り直す（AVMutableComposition＋独自合成の命令）
                         いいえ ▶ RenderGraph に新しい Project を渡すだけ（色・位置・エフェクトは即反映）
                                       ▼
          AVPlayer（プレビュー）／AVAssetReader（書き出し）が DistroCompositor を毎フレーム呼ぶ
                                       ▼
          FrameRenderer：下のトラックから順に 素材 → 補正 → 色 → マスク → 配置（3D）→ エフェクト → 重ね合わせ
                         （Core Image を Metal で実行。トランジション・字幕もここで描く）
```

- **Project は値型**（struct）。元に戻すは「前の値を持っておく」だけで済み、テストもしやすい。
- **Core はプラットフォームに依存しない純 Swift**。編集操作・解析・ファイル形式はここにあり、Linux でもテストする。
- **Engine は Apple のフレームワーク**（AVFoundation・Core Image・Vision・Speech・Accelerate）。macOS でも動くので、CI で実際に書き出しまでテストする。
- **UI は iPad 専用**。タイムラインは描画と指の操作が多いため UIKit（`TimelineCanvasView`）で描き、ほかは SwiftUI。

## 時刻

`Time` は 1 秒 = 60,000 ティックの整数。24・25・30・48・50・60・120fps と 29.97fps を誤差なく表せるので、クリップの間に浮動小数点の誤差で 1 コマの隙間ができない。AVFoundation へは `CMTime(value:timescale: 60000)` でそのまま渡す。

## 合成の組み立て（CompositionBuilder）

1. 黒い短い動画（`PlaceholderVideo`）を全体の長さに引き伸ばして土台にする。画像やテキストだけでも合成処理が毎フレーム呼ばれる。
2. 動画クリップは、重ならないものどうしで合成トラックを使い回す。メイントラックのトランジションの前後には素材の「のりしろ」を足す（素材が足りなければ端のコマを止める）。
3. 速度カーブは一定速度の小区間に分け、`scaleTimeRange` で伸縮する。逆再生は前もって逆順の動画を作っておく。
4. 音声は同じように使い回し、音量（キーフレーム・フェード・自動そろえ）を `AVAudioMix` の直線ランプで表す。
5. 切れ目ごとに `DistroInstruction` を作り、全体を隙間なく覆う。

## ファイル

| 場所 | 中身 |
| --- | --- |
| `Documents/Projects/<ID>.disve` | プロジェクト（JSON）。ファイル App から見える |
| `Documents/Projects/<ID>.jpg` | 一覧用のサムネイル |
| `Documents/Media/` | コピーした素材・内蔵 BGM・手書き・フリーズ画像、`Proxies/`・`Reversed/`・`ProcessedAudio/` |
| `Application Support/DistroVE/Backups/<ID>/` | 世代バックアップ（最大 20） |
| `Application Support/DistroVE/LUTs/` | 読み込んだ LUT |
| `Application Support/DistroVE/Content/` | GitHub から受け取ったテンプレート・LUT（`ContentPending/` から次回起動時に入れ替え） |
| `Application Support/DistroVE/Diagnostics/` | 動作ログ・クラッシュログ（MetricKit）・同意した使用回数 |
| `Caches/DistroVE/` | 音声の特徴量・元に戻すの履歴・書き出し・作業用（容量が 2GB を超えると古いものから消す） |

`.disve` は形式番号（`formatVersion`）を持ち、知らない項目は無視し、無い項目は既定値で読む。新しい形式のファイルは「アプリを更新してください」と断る。

## スレッド

- `EditorController` と画面はメインスレッド（`@MainActor`）。
- 合成・書き出し・解析は `async` 関数でメインスレッドの外に出し、終わったら `apply` で結果を反映する。
- 独自合成（`DistroCompositor`）は AVFoundation の専用キューから呼ばれる。描画中に読むプロジェクトは `RenderGraph` がロック付きで持つ。
